# ¿Entra? — Contador de caracteres

Contador en español para revisar el largo de publicaciones antes de compartirlas. Está hecho con HTML, CSS y JavaScript puro, sin dependencias de ejecución ni proceso de compilación.

## Uso

Abrí `index.html` en un navegador. El contador muestra caracteres, palabras, tiempo estimado de lectura y el espacio restante según la plataforma elegida.

Plataformas incluidas: Instagram, X, TikTok, LinkedIn, YouTube y meta description.
